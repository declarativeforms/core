---
title: "Use OpenAI Codex"
description: "Configure OpenAI Codex with Declarative Forms documentation context and prompt it to create or edit valid YAML forms."
---

Use OpenAI Codex when you want an agent to edit form YAML directly in your repository.

## Add context

Give OpenAI Codex the full Mintlify docs context:

```text
https://docs.declarativeforms.com/llms-full.txt
```

If you want OpenAI Codex to inspect a smaller index first, use:

```text
https://docs.declarativeforms.com/llms.txt
```

## Generate a new form

Use this prompt when you want OpenAI Codex to create a new YAML file:

```text
Read the Declarative Forms docs from https://docs.declarativeforms.com/llms-full.txt.

Create a new Declarative Forms YAML file for <form purpose>.

The form should:
- Collect <fields to collect>.
- Validate <required validation rules>.
- Send submissions to <email address or webhook URL>.
- Show <completion message or routing behavior>.

Implementation rules:
- Use version: 1.
- Use documented Declarative Forms YAML only.
- Keep ids lowercase and snake_case.
- Prefer a minimal, readable YAML file.
- Add comments only where they clarify conditional logic or integrations.
- After the YAML, list any assumptions.
```

## Edit an existing form

Use this prompt when OpenAI Codex is working in a repository that already has a form file:

```text
Use the Declarative Forms docs at https://docs.declarativeforms.com/llms-full.txt.

Update <path-to-form.yaml> to <describe the change>.

Constraints:
- Preserve existing field ids unless a rename is explicitly required.
- Preserve unrelated sections, connections, completion settings, and theme settings.
- Keep the YAML valid and minimal.
- Explain what changed and how to test the form.
```

## What to check

After OpenAI Codex edits the file, review the diff for unrelated rewrites. Then open the form URL and test required fields, conditional logic, section navigation, and configured connections.
