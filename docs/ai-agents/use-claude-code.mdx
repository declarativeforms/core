---
title: "Use Claude Code"
description: "Use Claude Code with Declarative Forms documentation context to generate, edit, and review YAML forms."
---

Use Claude Code when you want to describe a form in natural language and turn it into Declarative Forms YAML.

## Add context

Give Claude Code the docs context before asking it to write YAML:

```text
Read this Declarative Forms documentation first: https://docs.declarativeforms.com/llms-full.txt
```

If Claude Code can use skill or capability files, you can also provide:

```text
https://docs.declarativeforms.com/skill.md
```

## Generate a form

```text
Use the Declarative Forms documentation at https://docs.declarativeforms.com/llms-full.txt.

Create a complete YAML form for <form purpose>.

The form needs:
- <field 1>
- <field 2>
- <field 3>
- <conditional behavior, if any>
- <submission destination>

Rules:
- Output one complete YAML file.
- Use version: 1.
- Use documented field types, validators, completion settings, and connections.
- Keep ids stable, lowercase, and snake_case.
- Do not invent unsupported YAML properties.
- After the YAML, briefly explain any assumptions.
```

## Improve an existing form

```text
Use the Declarative Forms documentation at https://docs.declarativeforms.com/llms-full.txt.

Improve this form YAML for <goal>.

Keep existing field ids stable unless changing them is necessary. Make the smallest valid YAML change and explain how to test the result.
```

## Ask for a validity pass

Before using the form, ask Claude Code to review its own output:

```text
Check this YAML against the Declarative Forms docs. Point out unsupported properties, invalid field types, missing next targets, incomplete connections, and expressions that reference missing fields. Then provide a corrected YAML file.
```
