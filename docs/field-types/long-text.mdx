---
title: "Long text"
---

If you have not created a form before, start with [Create a form](/getting-started/create-a-form).

```yaml form.yaml
version: 1
title: "Example form"
description: "A comprehensive long_text example."

sections:
  - id: section_1
    title: "Section 1"
    fields:
      - id: question_1
        type: long_text
        label: "Question 1"
        placeholder: "Type a longer answer"
        validators:
          - required
          - type: pattern
            regex: "^[A-Za-z0-9 .,!?'-]+$"
            message: "Use letters, numbers, and common punctuation only."
          - type: min_length
            value: 20
            message: "Enter at least 20 characters."
          - type: max_length
            value: 500
            message: "Enter no more than 500 characters."
          - type: expression
            expression: "data.question_1.includes('example')"
            message: "Include the word example."

    next: done
```
