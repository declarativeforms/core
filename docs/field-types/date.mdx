---
title: "Date"
---

If you have not created a form before, start with [Create a form](/getting-started/create-a-form).

```yaml form.yaml
version: 1
title: "Example form"
description: "A comprehensive date example."

sections:
  - id: section_1
    title: "Section 1"
    fields:
      - id: question_1
        type: date
        label: "Question 1"
        validators:
          - required
          - type: min
            value: "2026-01-01"
            message: "Use a date on or after 2026-01-01."
          - type: max
            value: "2026-12-31"
            message: "Use a date on or before 2026-12-31."

    next: done
```
