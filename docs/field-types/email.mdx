---
title: "Email"
---

If you have not created a form before, start with [Create a form](/getting-started/create-a-form).

```yaml form.yaml
version: 1
title: "Example form"
description: "A comprehensive email example."

sections:
  - id: section_1
    title: "Section 1"
    fields:
      - id: question_1
        type: email
        label: "Question 1"
        placeholder: "name@example.com"
        block_free_email: true
        otp: true # Sends a verification code and requires verification before continuing.
        validators:
          - required
          - type: pattern
            regex: "^[^@\\s]+@example\\.com$"
            message: "Use an @example.com address."
          - type: expression
            expression: "data.question_1 !== 'blocked@example.com'"
            message: "Use a different email address."

    next: done
```
