title: "Mobile number"
---

If you have not created a form before, start with [Create a form](/getting-started/create-a-form).

```yaml form.yaml
version: 1
title: "Example form"
description: "A comprehensive mobile_number example."

sections:
  - id: section_1
    title: "Section 1"
    fields:
      - id: question_1
        type: mobile_number
        label: "Question 1"
        placeholder: "+49 151 23456789"
        validators:
          - required
          - type: pattern
            regex: "^\\+[0-9 ]+$"
            message: "Start with + and use digits or spaces only."
          - type: min_length
            value: 8
            message: "Enter at least 8 characters."
          - type: max_length
            value: 20
            message: "Enter no more than 20 characters."

    next: done
```
