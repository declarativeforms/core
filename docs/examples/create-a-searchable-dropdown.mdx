---
title: "Create a searchable dropdown"
---

If you have not created a form before, start with [Create a form](/getting-started/create-a-form).

```yaml form.yaml
version: 1
title: "Country selector"
description: "A simple form with a dropdown that can be searched."

sections:
  - id: section_1
    title: "Your details"
    fields:
      - id: country
        type: dropdown
        label: "Country"
        placeholder: "Search for a country..."
        searchable: true
        options:
          - label: "United States"
            value: "US"
          - label: "United Kingdom"
            value: "GB"
          - label: "Canada"
            value: "CA"
          - label: "Australia"
            value: "AU"
          - label: "Germany"
            value: "DE"
        validators:
          - required

    next: done
```
