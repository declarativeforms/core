---
title: "Require a work email address"
---

If you have not created a form before, start with [Create a form](/getting-started/create-a-form).

```yaml form.yaml
version: 1
title: "Demo request"
description: "A simple form that asks for a work email address."

sections:
  - id: section_1
    title: "Your details"
    fields:
      - id: email
        type: email
        label: "Work email"
        placeholder: "name@company.com"
        # Blocks common free email providers.
        block_free_email: true
        validators:
          - required

    next: done
```
