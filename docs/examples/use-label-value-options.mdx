---
title: "Use label/value options"
---

If you have not created a form before, start with [Create a form](/getting-started/create-a-form).

```yaml form.yaml
version: 1
title: "Lead source"
description: "A simple form that stores stable values for human-readable options."

sections:
  - id: section_1
    title: "Your details"
    fields:
      - id: full_name
        type: short_text
        label: "Full name"
        validators:
          - required

      - id: lead_source
        type: single_select
        label: "How did you hear about us?"
        options:
          - label: "Search engine"
            value: "search"
          - label: "Social media"
            value: "social"
          - label: "Friend or colleague"
            value: "referral"
          - label: "Advertisement"
            value: "ad"
        validators:
          - required

    next: done
```
