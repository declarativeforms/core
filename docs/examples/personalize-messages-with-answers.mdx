---
title: "Personalize messages with answers"
---

If you have not created a form before, start with [Create a form](/getting-started/create-a-form).

```yaml form.yaml
version: 1
title: "Demo request"
description: "A simple form that uses answers in follow-up messages."

sections:
  - id: section_1
    title: "Your details"
    fields:
      - id: full_name
        type: short_text
        label: "Full name"
        validators:
          - required

      - id: email
        type: email
        label: "Email address"
        validators:
          - required

      - id: company
        type: short_text
        label: "Company"
        validators:
          - required

    next: done

completion:
  title: "Thanks, {{data.full_name}}"
  message: "We will follow up with {{data.email}} about {{data.company}}."

connections:
  - type: email
    to: "sales@example.com"
    subject: "Demo request from {{data.full_name}} at {{data.company}}"
    body: "Reply to {{data.email}}."
    include_responses: true
```
